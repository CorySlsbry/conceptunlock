## Overview

ConceptUnlock is a mobile-first PWA built for college students, medical/law students, and nursing candidates drowning in textbook material. It installs on iOS, Android, and desktop from the browser, works offline, and ships to the Microsoft Store and Google Play Store (via Bubblewrap / TWA).

## Features

- **Mobile-first UI** — Optimized for phones, scales to tablet and desktop
- **Installable PWA** — Service worker + manifest, zero app store friction
- **Stripe Billing** — Subscription management with the refer-2-for-20% loop
- **Supabase Auth** — Email sign-in with per-app schema isolation
- **Store-ready** — Ships to Microsoft Store directly, Google Play via TWA

## Getting Started

1. Clone this repo
2. Copy `.env.example` to `.env.local` and fill in your keys
3. Run `npm install`
4. Run `npm run dev`
